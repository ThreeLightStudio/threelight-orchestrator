# ThreeLight Orchestrator — Codex

독립적으로 유지하거나 사용자가 나중에 이어갈 작업은 별도 세션이 책임진다. 조사·검토 같은 제한된 보조 작업은 메인이나 작업 세션의 서브에이전트에 맡길 수 있다. 작은 작업은 서브에이전트만 사용한다. 항상 둘 다 만들 필요는 없다.

## 먼저 확인할 것

- 이 설치본은 **Codex 전용**이다. 실제 실행 환경과 사용 가능한 도구를 확인한다. 다른 환경이면 작업자를 만들지 않고 알맞은 설치본을 안내한다. 이름이나 모델 제공자만으로 환경을 추정하지 않는다.
- 스킬 호출, 아이디어 논의, 계획 작성, 스킬 자체의 수정은 작업자 실행 요청이 아니다. 실행 대상·범위·완료 기준과 사용자의 실행 의도가 정해질 때까지 현재 대화에서 논의한다.
- 명시적으로 승인된 실행 범위 안에서 진행한다. 스킬 선택은 세션 생성·위임·외부 메시지·예약 실행의 추가 권한을 만들지 않는다. 이미 승인된 실행을 단계마다 다시 확인하지 않는다.
- 지원하지 않는 도구·인수·지속성·재개·자동화를 추정하지 않는다. 현재 도구 스키마와 권한이 우선이다.

## 진행 순서

1. 목표·포함/제외 범위·원하는 결과·핵심 미정 사항을 정리한다. 조사로 해결할 수 있는 것은 먼저 확인한다.
2. [공통 운영 규칙](references/operating.md)에 따라 작업·의존성·소유권·검토 기준·전체 동시 실행 상한을 정한다. 승인된 선행 결과만 후속 입력으로 사용한다.
3. 아래 환경별 실행 참조를 필요한 시점에 읽고 작업자를 배정한다. 작업자 완료는 검토 시작 신호다.
4. [기록과 재개](references/records.md)에 따라 현재 상태와 근거를 남긴다. 무변화 감시는 조용히 끝내고, 완료·실패·사용자 판단 필요처럼 의미 있는 변화만 알린다.
5. 개별 결과와 최종 통합의 완료 기준을 검증한 뒤 산출물·검증·제한을 인계한다. [측정과 배정](references/measurement-and-scheduling.md)은 실행 계획, 의미 있는 전환, 종료 집계 때 필요한 절만 읽는다.
