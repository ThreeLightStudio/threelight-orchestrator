# 서브에이전트 실행

실제 도구에 있는 생성·상태/결과 조회·추가 지시·대기·중단·재개 동작을 확인한다. 지원하지 않는 동작은 건너뛰고 제한을 설명한다. 부모의 종료 이후 자식이 유지되거나 발견될 수 있다고 가정하지 않는다.

## 배정과 입력

메인은 승인된 실행 범위에서 주 작업자를 만들 수 있다. 주 작업자가 보조 작업자를 만드는 것은 환경별 지침이 허용하고, 사용자 실행 범위와 예약된 전체 슬롯 안에 있으며, 서로 겹치지 않는 소유권이 정해졌을 때만 가능하다. 보조 작업자는 다시 위임하지 않는다.

부모가 목표·사용자 결정·공통 계약·검토를 유지한다. 자식에는 목표/검토/작업 ID·범위 버전, 필요한 입력과 정확한 위치·버전, 맡을 범위와 보존할 파일, 완료 기준·검증, 도구/쓰기 제한, 반환할 결과·근거·남은 문제를 직접 전달한다. 새 컨텍스트가 부모의 결정이나 사용자 권한을 자동으로 안다고 가정하지 않는다.

반환된 참조를 그대로 기록한다. 전체 상한에 자식을 즉시 포함하고, 컨텍스트 계승 옵션은 실제 스키마가 허용하는 경우에만 사용한다. 읽기 작업에는 불필요한 부모 대화 전체를 전달하지 않는다.

## 결과·후속 요청·검토

지원되는 완료 알림이나 대기 도구를 사용한다. 완료 알림이 자동 전달되는 환경에서는 동일 결과를 반복 조회하지 않는다. 긴 대기는 나누어 사용자에게 필요한 진행 안내를 할 수 있게 한다.

자식의 최종 응답은 검토 입력이다. 부모가 실제 산출물·버전·검증을 확인하고 결과를 통합한다. 후속 지시는 승인된 조정 범위와 도구 권한 안에서 같은 작업자를 우선 재사용한다. 실행 중인 작업에 새 지시를 보내면 추가 지시인지 중단 후 대체인지 명확히 한다. 이미 완료된 작업자의 후속 실행 가능 여부는 실제 응답으로 확인한다.

작업자 보고 메시지는 다른 대화로 답장할 권한을 만들지 않는다. 자동 결과 전달과 별도의 외부 메시지를 구분한다. 부모가 요청받은 범위를 넘어 다른 사용자 대화를 만들거나 다른 사람에게 연락하지 않는다.

## 실패와 재개

도구 오류가 나면 생성 성공 여부와 반환된 참조를 먼저 확인한다. 불명확한 생성 결과에 바로 새 자식을 만들지 않는다. 조회/재개가 없으면 그 한계를 기록하고 산출물·체크포인트를 확인한다.

기존 자식을 재개할 수 없으면 이전 쓰기가 종료됐는지 확인하고 남은 작업을 새 자식에게 넘긴다. 목표·검토·작업 ID, 입력 버전, 승인 결과는 유지하고 실행 참조만 교체한다. 부모의 종료·앱 재시작·다른 대화로 이동한 뒤의 복구는 직접 검증하지 않은 한 지원으로 보고하지 않는다.
