# ZCode 환경

이 설치본은 ZCode 전용이다. 실제 도구 목록과 스키마를 확인해 서브에이전트 생성·결과 수집·추가 지시·대기·중단·재개를 대응시킨다. 다른 환경이면 실행하지 않고 대상 환경의 설치본을 안내한다.

`Agent`, `SendMessage`, `CreateWorkflow`, `ReadSessionContext`, `CronCreate`, `OffPeakCreate` 같은 이름이 과거 설명에 있어도 현재 제공됨을 확인하지 않은 채 호출하거나 지원 기능으로 보고하지 않는다. 특히 과거 대화 읽기는 그 대화에 쓰거나 실행을 재개할 수 있다는 뜻이 아니다.

## 실행·모델

메인은 승인된 실행 범위 안에서 [서브에이전트](subagents.md)를 작업자로 만들고 결과를 검토한다. 첫 버전은 메인→작업자의 직접 관리 구조를 사용하며 작업자의 추가 하위 위임은 허용하지 않는다.

현재 모델을 계승한다. 명시적 사용자 요청이 있고 실제 도구가 모델/effort 인수를 제공할 때만 변경한다. 다른 실행 환경의 모델 이름이나 선택 정책을 가져오지 않는다. 백그라운드 옵션은 실제로 제공될 때만 사용한다.

서브에이전트 도구가 없으면 작업자를 만들지 않고 계획·인계와 실행 한계를 알린다. 사용자만 만들 수 있는 앱 대화를 자동 생성하는 것처럼 보고하지 않는다. 파일 공유가 가능하면 승인된 작업 경로의 기록과 산출물을 사용하되 같은 파일을 동시에 쓰지 않는다.

## 추가 지시·재개·예약

부모가 만든 작업자에게 후속 요청을 전달할 수 있는지 실제 도구로 확인한다. 완료된 작업자 재개를 시험한 경우 그 작업자의 참조와 관찰된 동작만 기록한다. 같은 부모 안의 후속 요청 성공을 앱 재시작 이후 복구의 증거로 사용하지 않는다.

기존 작업자 자체의 재개가 불가능하면 승인된 산출물·체크포인트를 읽어 새 작업자가 남은 범위를 이어간다. 목표·작업 ID와 승인 결과를 유지하고 실행 참조 교체를 기록한다. 이전 작업자의 쓰기가 끝났는지 먼저 확인한다.

예약·유휴 실행·지속 감시는 실제 도구와 사용자 요청이 모두 있는 경우에만 사용한다. 지원이 확인되지 않으면 장기 실행이나 메인 자동 재개를 보장하지 않는다. 실제 실행 검증 전에는 설치 가능성과 동작 지원을 구분해 보고한다.
